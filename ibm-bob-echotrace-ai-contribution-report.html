Security & Quality Audit — Findings Fixed by Bob
🔴
S1 · API Docs Exposed in Prod
/docs and /redoc were accessible in all environments, exposing the full API schema.
✓ Gated behind settings.DEBUG flag
🔴
S2 · Table Creation at Import
create_all() ran at module load time, not during application startup.
✓ Moved to async lifespan() event
🔴
S7 · Deprecated datetime.utcnow
datetime.utcnow() is deprecated since Python 3.12 and produces naive datetimes.
✓ Replaced with datetime.now(timezone.utc)
🔴
S8 · ReDoS Surface
Trust engine ran all regex patterns against up to 16 KB inputs with no length guard.
✓ Added 20,000-char defensive truncation
🟡
P1 · Sequential Engine Execution
All five analysis engines ran one after another in a single thread, wasting multi-core capacity.
✓ Refactored to ThreadPoolExecutor(max_workers=5)
🟡
P4 · O(n) Bias Regex Loop
_find_matches() called re.search() per term inside analyze() — one pass per vocabulary word.
✓ Replaced with two pre-compiled alternation regexes
🟡
P5 · SVG Recomputed Every Render
ScoreGauge recomputed all arc geometry on every parent re-render.
✓ Wrapped geometry in useMemo([score, size])
🔵
Q2 · Broken GET /report/:id Schema
trust_engine field was missing from the report endpoint response, causing Pydantic validation failure.
✓ Reconstructed valid trust_engine payload from DB
Key Design Decisions Made by Bob
"Use rule-based heuristics — no external LLM calls. Zero latency, zero API cost, fully deterministic output for the hackathon demo."
— Bob, Prompt 1 architecture session
"The trust score is an integer 0–100 derived from a weighted penalty formula across six independent signals. Both extremes — too uncertain AND too overconfident — erode the real confidence score."
— Bob, Trust Engine design, Prompt 4 & 7
"PDF generation runs entirely in memory via ReportLab. No temp files, no disk I/O — the bytes are streamed directly from FastAPI with Content-Disposition: attachment."
— Bob, PDF builder design, Prompt 8
